# General Information
This repository contains the data used in the publication titled: "Release of microplastics and metals from antifouling paint during weathering in simulated cold climates" . The dataset contains raw data and processed data files for the analysis undertaken in the paper. 

Title of Dataset: Release of microplastics and metals from antifouling paint during weathering in simulated cold climates

# Data and File Overview
Files in this repository are organized based on the Figures in the manuscrcipt. Each folder contains folders that contain raw data, processed data and corresponding figures.

Abbreviations: 
CC: Cold Control
HC: Heat Control
FT: Freeze-thaw
UV: Ultraviolet radiation
SP-ICP-MS: Single-Particle Inductively Couped Plasma Mass Spectrometry
ICP-MS: Inductively Couped Plasma Mass Spectrometry
O-PTIR: Optical Photothermal Infrared spectroscopy
